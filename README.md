# ActPrune: Action-Grounded Visual Token Pruning for Efficient Vision-Language-Action Models

Sungwon Moon<sup>1</sup>, Minji Kim<sup>2</sup>, Hyemin Boo<sup>2</sup>, Daeun Song<sup>2†</sup>, Jiyoung Lee<sup>1,2†</sup>

## Overview
ActPrune is a training-free visual token pruning method for VLA models. It uses the action chunk predicted at the previous step as a geometric prior to prune visual tokens before the vision encoder, with view-specific strategies for the fixed third-person and wrist cameras.
